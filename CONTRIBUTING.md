# Contributing to ai-audit-shelf

Thanks for your interest in improving this project!

## How to Contribute

- **Questions, Feature Requests, Bugs:** Open an issue.
- **Pull Requests:** Fork the repo, make your changes, and submit a PR.
- **Coding Style:** Follow existing patterns (PEP8 for Python).
- **Tests:** Please test your changes before submitting.

## Good First Issues

Check [open issues labeled "good first issue"](https://github.com/ATHARVA262005/ai-audit-shelf/labels/good%20first%20issue).

Thanks for helping make ai-audit-shelf better!
